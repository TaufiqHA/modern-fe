# 🛍️ Modern Store
**A Premium E-commerce Experience for Modern Brands.**

Modern Store is a feature-rich storefront prototype built for speed, aesthetics, and functionality. It features a curated product catalog, a unique "Jastip" service, and a comprehensive management dashboard.

---

## ✨ Key Features
- **Dynamic Catalog:** Browse products across multiple categories with a sleek UI.
- **Curated Collections:** Discover themed product groups (e.g., Modern Essentials, Linen Series).
- **Jastip Service:** Request personal shopping services directly through the platform.
- **Admin Dashboard:** Manage products, track orders, and handle user requests in one place.
- **Responsive Design:** Optimized for mobile, tablet, and desktop using Tailwind CSS.
- **Smooth Animations:** Powered by Framer Motion for a premium feel.

## 🛠️ Tech Stack
- **Frontend:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Routing:** React Router 7

## 🚀 Getting Started

### Prerequisites
- Node.js (LTS version)
- A Gemini API Key (Optional, for AI features)

### Installation
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   - Create a `.env.local` file based on `.env.example`.
   - Add your `GEMINI_API_KEY`.

### Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
